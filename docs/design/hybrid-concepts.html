🔭 H1 — Le Double Zoom

Fusion Village (A) + Cité des Flux (B) — zoom continu entre macro et micro
FluideBicoucheImmersif
Screenshots imaginaires
🏙️ Zoom OUT — La Cité

Vue isométrique sur fond anthracite. Métropole compacte de blocs colorés par domaine (teal = data, violet = dev, orange = ops). Convoyeurs animés entre bâtiments. HUD discret en haut : Workers actifs · Débit total · Erreurs. Les bâtiments actifs pulsent. Un en erreur clignote rouge, ses convoyeurs éteints. 93 projets lisibles d'un coup.

🌀 La Transition (~2 secondes)

La caméra descend. Les blocs grandissent, des fenêtres apparaissent, puis des toits colorés. Les convoyeurs se transforment en chemins de terre. Les cubes de données ralentissent et deviennent organiques — un cube teal devient un pigeon messager. Le fond anthracite s'éclaircit vers un ciel pixel-art. La musique électronique crossfade vers un thème acoustique chaleureux.

🏡 Zoom IN — Le Village

Vue top-down inclinée. Maisons chaleureuses avec personnalités fortes — panoramax3d a une lunette sur le toit, BigEndpoint est une forge fumante. Villageois nommés : KnowledgeBuilder lit sous un arbre, GitWatcher fait sa ronde. Chemins de terre usés par le passage. Sons de pas, oiseaux, forge.

Boucle joueur
0–2 min
Survol.

Démarrage en vue macro. Lecture des flux actifs. Repérage d'un quartier animé et d'un autre éteint.

2–5 min
Plongée.

Zoom sur le quartier animé. Transition fluide. Village vibrant. Entrée dans une maison, conversation avec le villageois.

5–10 min
Diagnostic.

Re-zoom macro → quartier éteint → zoom dedans. Village fantôme. Panneau de mairie : aucune mission depuis 3 jours.

10–15 min
Action.

Spawn d'un worker depuis le panneau. Villageois apparaît, cheminée s'allume. Re-zoom macro : un nouveau convoyeur vient de naître.

5 Moments forts
01
Le Premier Plongeon

Les blocs froids se transforment en maisons chaleureuses. "Oh, il y a des gens là-dedans." Lien émotionnel immédiat.

02
L'Orage vu d'en haut

Un quartier entier passe en rouge en macro. On zoome dedans → village sous orage violent. L'urgence systémique a une traduction émotionnelle.

03
Le Convoyeur qui devient Rivière

À mi-zoom entre deux quartiers très liés, le convoyeur se transforme en ruisseau avec des bateaux en papier.

04
La Vue depuis la Tour

Depuis le sommet de la Tour WikiChat : un entre-deux poétique entre les toits des quartiers et les convoyeurs lointains.

05
Le Nouveau Quartier émerge

En macro : terrain vague → agent scout plante un drapeau → première maison construite en accéléré à chaque revisitation.

Mécaniques core
01
Zoom continu

Molette ou pinch sans coupure. LOD progressif — 3 paliers snap : Cité / Quartier / Village.

02
Clic contextuel bicouche

Macro → panel stats. Micro → entrer dans la maison. Même geste, résultat adapté.

03
Drag & drop workers

Fonctionne depuis les deux niveaux. En micro : on voit le villageois arriver physiquement.

04
Mini-map inverse

En micro : mini-map montre la vue macro du quartier. En macro : pas de mini-map (on y est).

05
Alertes multi-niveaux

Macro = badge rouge. Micro = orage + villageois anxieux. Même info, deux registres.

06
Panneau de mairie (micro only)

Force à "entrer" dans un quartier pour agir. Lecture du courrier .wikichat/.

Limites
Double budget artistique

Chaque élément existe en version bloc isométrique ET maison pixel-art.

LOD complexe

Charger/décharger deux styles sans lag demande un pipeline graphique solide.

Zone intermédiaire floue

Le zoom 40-60% peut sembler ni l'un ni l'autre. Nécessite un palier "quartier" convaincant.

Mémoire des états micro

Garder les positions de villageois même en vue macro. Solution : figer et "réveiller".

Transposition technique
# Macro
Convoyeurs animés   → Canvas lignes + particules (rAF)
Clic bâtiment       → GET /api/projects/:slug → panel stats
Badge erreur        → SSE event project_error → sprite swap

# Transition
LOD progressif      → 3 spritesheets selon palier de zoom
Morphing convoyeur  → Interpolation CSS/Canvas géométrique → organique
Son crossfade       → Web Audio API, deux pistes avec gain croisé (~2s)

# Micro
Villageois A*       → Pathfinding simple sur grille
Entrer maison       → GET /api/projects/:slug/wikichat/artifacts
Orage               → Particle system déclenché par SSE event erreur
Panneau mairie      → POST /api/spawn/headless {project, prompt}
🟢 Prototype minimum

3-5 bâtiments en macro + scroll zoom → maisons en micro. Un convoyeur qui devient chemin de terre. En micro : 3 maisons, 1 villageois chacune, clic = 2-3 artifacts réels. Deux pistes audio crossfade selon zoom.

Validation : Si le joueur zoome naturellement d'avant en arrière sans que la transition le sorte de l'immersion, ça fonctionne.

🚋 H2 — La Ville par Quartiers

Pokémon · Night in the Woods · Mini Metro — clustering thématique avec transports inter-quartiers
QuartiersTramwaysVoisinage
Screenshots imaginaires
🏘️ Vue Quartier (par défaut)

Vue top-down 2.5D légèrement isométrique, palette GBA chaude. Quartier Dev : 6 maisons sur une rue pavée. panoramax3d = atelier en brique rouge avec maquette 3D sur le toit. BigEndpoint = hangar industriel reconverti, lumière orange à l'intérieur. En haut : "📍 Quartier Dev — 12 projets · 4 agents actifs". Au bout de la rue : un boulevard avec un tramway teal chargé de colis colorés.

🗺️ Vue Ville (dézoom molette)

5 quartiers visibles comme des îlots colorés : Dev (bleu-gris, nord), Data (violet, est), Ops (orange, sud), Design (rose, ouest), Place WikiChat (teal, centre). Entre eux : boulevards avec tramways en boucle (3 tramways = boulevard actif, 1 toutes les 30s = boulevard calme). Des pigeons messagers traversent le ciel entre quartiers éloignés. Un pneumatique transparent relie deux quartiers adjacents — les capsules filent dedans.

Boucle joueur
0–5 min
Place WikiChat.

Réveil. Mairie avec panneau : "Dev — 3 artifacts ce matin", "Data — KB terminée". Choix : marcher ou prendre le tramway vers le Quartier Dev.

5–15 min
Exploration de quartier.

Entrer dans une maison, voir les étagères, parler au villageois Architect qui demande une analyse. Aller au panneau du quartier → créer une mission → agent headless apparaît à la gare locale.

15–30 min
Vue ville.

Boulevard Dev↔Data saturé (5 tramways). Clique sur boulevard → "ajouter ligne express". Quartier Design sans tramway → aller à pied investiguer.

30 min+
Urbanisme.

Déplacer un projet entre quartiers, créer un nouveau quartier pour un domaine émergent, tracer une nouvelle ligne directe entre deux projets très liés.

5 Moments forts
01
Inauguration d'un quartier

Assez de projets d'un même domaine → cérémonie de fondation, défilé de villageois, ruban coupé, premiers tramways.

02
Embouteillage sur le boulevard

Trop d'artifacts en transit, tramways bondés, file d'attente. Le joueur doit créer une ligne express ou scinder un quartier.

03
Le quartier fantôme

Maisons poussiéreuses, volets fermés, tramway à vide. Ambiance mélancolique. Relancer un projet → lumières qui se rallument une à une.

04
Visite inter-quartier

Un villageois de Data marche seul dans les rues de Dev avec un gros colis. Sonne. Les deux se serrent la main. Nouveau lien sur la carte.

05
Le marché du samedi

Événement périodique : représentants de tous les quartiers sur la Place WikiChat avec des stands d'artifacts. Découverte cross-domaines.

Mécaniques core
01
Marche + tramways

ZQSD libre. Monter dans un tramway = fast-travel vers un autre quartier.

02
Panneau de quartier

Chaque quartier a son panneau de missions local. La Place WikiChat = missions inter-quartiers.

03
Gestion des boulevards

Tracer, renforcer, couper des lignes. Les véhicules (tramway/pigeon/pneumatique) selon le type de donnée.

04
Requalification

Glisser une maison d'un quartier à l'autre. Animation de déménagement avec camion.

05
Fondation de quartier

3+ projets orphelins de même domaine → créer un nouveau quartier, choisir son style et sa couleur.

06
Carte murale

Dans la mairie : grande carte avec flux en temps réel. Mode surveillance depuis le monde du jeu.

Limites
Projets hybrides

Un projet Data+Dev est difficile à placer dans un seul quartier. Mitigation : "ambassade" dans un quartier secondaire.

Gestion spatiale

Le joueur doit gérer le layout physique. Peut être perçu comme du travail supplémentaire.

Temps de trajet

Se déplacer entre quartiers prend du temps même avec les tramways. Frustrant en cas d'urgence.

Quartiers vides

1-2 projets ne justifient pas un quartier → "Quartier Divers" fourre-tout qui perd l'identité.

Transposition technique
Entrer dans maison      → GET /api/projects/:slug/wikichat/artifacts
Panneau de quartier     → GET /api/projects?domain=:quartier
Créer mission           → POST /api/spawn/headless {project, prompt}
Tramway transporte      → SSE event artifact partagé entre projets
Boulevard saturé        → count(messages inter-quartier) / timeWindow > seuil
Carte murale            → GET /status + SSE live updates
Pigeon messager         → SSE event: direct_message entre quartiers différents
Fondation quartier      → POST /api/quartiers {name, domain, projects[]}
Marché du samedi        → CRON + broadcast "market" + GET /api/artifacts/recent?cross=true
🟢 Prototype minimum

Deux quartiers (3 maisons chacun) reliés par un boulevard avec un tramway. Marche libre, entrée dans les maisons, prise du tramway inter-quartier. Quand un artifact est partagé, on voit un colis se charger dans le tramway et traverser le boulevard.

Validation : Si le joueur veut spontanément créer un troisième quartier et tracer un nouveau boulevard, ça fonctionne.

✨ H3 — Les Auras Vivantes

Village chaleureux + flux comme halos colorés + overlay data sur demande [L]
LumineuxOrganiqueLisible
Screenshots imaginaires
🌆 Vue Village (crépuscule, mode par défaut)

Village top-down chaleureux, palette terre/vert/teal. Chaque maison émet un halo coloré qui pulse : panoramax3d = halo teal vif qui s'étend sur 3 tuiles. BigEndpoint = halo violet profond avec particules qui convergent vers sa porte. Une maison en retrait = halo rouge clignotant, les villageois voisins la regardent avec inquiétude. Entre les maisons : des fils lumineux reliant les projets connectés — épais = débit fort, éteint (gris) = connexion dormante.

🔬 Vue Lunette d'Architecte [L] maintenu

Même perspective, pas de changement d'échelle. Un overlay semi-transparent se superpose : les maisons deviennent des silhouettes, les auras s'intensifient ×3 et révèlent leur débit ("12 msg/min", "3 artifacts/h"). Les fils s'épaississent comme des artères. Les villageois disparaissent → remplacés par des icônes de rôle (engrenage=worker, loupe=analyst, livre=KB). Mini-graphe de dépendances en bas à droite. On relâche [L] → fondu 0.3s, retour au village chaud.

Boucle joueur
0–5 min
Réveil, lecture des auras.

En sortant, on voit les halos du voisinage. Une aura rouge attire l'œil → on marche vers la maison, on entre, l'agent explique le problème.

5–15 min
Exploration par les fils.

Un fil très actif entre deux maisons distantes → on le suit à pied. On croise des villageois porteurs d'artifacts (halo doré). On découvre un nouveau projet.

15–30 min
Diagnostic via [L].

Activer la lunette pour repérer un goulot (maison beaucoup d'entrées, peu de sorties). Accepter une mission, spawner un helper qui naît avec un halo vert.

5 Moments forts
01
L'Éveil des Auras

Premier lancement. Maisons grises. Le joueur lance son premier agent : une aura teal naît, puis un fil s'allume vers la cible. Le village s'éveille maison par maison.

02
La Cascade Dorée

Un artifact important partagé cross-projet. Un villageois marche avec halo doré intense. Il livre → double flash doré, carillon, fil qui brille 10s.

03
L'Orage d'Auras

5+ maisons en erreur simultanées. Halos rouges synchronisés comme un battement de cœur. Sous [L] : la propagation en cascade est visible. Tout le village vire sombre.

04
La Nuit Bioluminescente

La nuit, les auras et fils sont la seule lumière. Le village endormi ressemble à un réseau neuronal lumineux vu du dessus. Moment visuellement unique.

05
Le Fil Mort qui Renaît

Un fil gris éteint se rallume soudain. Une onde teal se propage d'un bout à l'autre. Les deux maisons émettent un "ding", leurs auras s'enrichissent d'une teinte.

Mécaniques core
01
Auras dynamiques

Teal=production, violet=messages entrants, doré=cross-projet, rouge=erreur, bleu=repos. Les auras se combinent.

02
Fils de connexion

Épaisseur=débit, couleur=type de flux, pulsation=fréquence. Fil éteint = connexion dormante. On peut le suivre physiquement.

03
Lunette d'Architecte [L]

Toggle maintenu. Overlay data sans changer de perspective. Métriques + graphe de dépendances.

04
Villageois-porteurs

Les agents transportant des artifacts marchent avec un halo doré. Le joueur peut les intercepter et voir ce qu'ils portent.

05
Cycle bioluminescent

Jour : auras subtiles. Nuit : auras = seule lumière. Agents nocturnes (cron jobs) n'apparaissent que la nuit.

06
Propagation d'état

Une erreur fait trembler les fils vers les dépendants. Un succès émet une onde positive. La santé du système est lisible autour de soi.

Limites
Surcharge visuelle

50+ maisons actives = bruit visuel. LOD nécessaire + regroupement des fils en faisceaux à distance.

Daltonisme

Système repose sur les couleurs. Mode accessibilité requis : formes/motifs en alternative.

Auras mixtes

Teal + violet + doré simultané = trop de couleurs. Aura dominante + indicateurs secondaires en orbite.

Fatigue [L]

Si le joueur reste en Lunette en permanence, il retombe dans un dashboard froid. Mitigation : flou progressif après 30s.

Transposition technique
Aura teal (production)  → Compteur share_artifact par unité de temps
Aura violet (messages)  → Compteur send_message reçus
Aura doré (cross-projet)→ Artifacts partagés cross-channel
Aura rouge (erreur)     → set_status "error" ou "blocked"
Fil lumineux            → Paire de sessions ayant échangé ≥1 msg/artifact
Épaisseur fil           → Nombre de msgs/artifacts sur les 10 dernières minutes
Lunette [L]             → Appel /status + overlay Canvas/SVG
Cycle jour/nuit         → Horloge réelle (ou accélérée ×60)
Agents nocturnes        → Cron tasks via register_cron
🟢 Prototype minimum (4 semaines)

S1 — 5 maisons avec auras CSS (radial gradients), polling /status toutes les 5s.
S2 — Fils Bézier animés entre maisons, épaisseur proportionnelle aux messages récents.
S3 — Overlay SVG [L] avec métriques numériques et fondu 0.3s.
S4 — Sprites villageois 16×16, halo doré sur les porteurs, cycle jour/nuit.

Validation : Si la nuit bioluminescente est un moment visuellement mémorable, la vision fonctionne.

⛵ H4 — Le Village sur la Rivière

Animal Crossing · Spiritfarer · Mini Motorways — les flux deviennent une rivière traversant le village
FluvialVivantLisible
Screenshots imaginaires
🌊 Vue Village (bord de l'eau)

Le joueur sur un pont en bois au centre. En contrebas : la Grande Rivière teal lumineux (`#00B4D8`), animée, semi-transparente, galets visibles au fond. Le long des rives : maisons sur pilotis ou construites au bord. panoramax3d = ponton avec longue-vue pointée vers l'amont. BigEndpoint = forge avec roue à aubes qui tourne. Plus une maison est active, plus elle est proche de la rive — les projets dormants sont dans les collines avec un chemin envahi d'herbe. Sur l'eau : bateaux en papier colorés — teal=artifact, bleu=message, violet=KB. Un agent Curator attrape un bateau avec une épuisette.

🏔️ Vue Colline (zoom out naturel)

Depuis la colline : vue panoramique du réseau hydrographique entier. Maisons = petits toits colorés. Bateaux = points qui dérivent. Zones actives = eaux vives, rapides, mousse blanche. Zones calmes = méandres, eaux lentes. Affluents visibles depuis les collines — actif = large et clair, tari = lit de cailloux secs qui clignote. C'est la vue macro, mais incarnée dans le paysage.

Boucle joueur
0–5 min
Réveil au bord de l'eau.

On sort, on entend l'eau couler. On descend au ponton. Un bateau teal passe — [A] pour l'attraper → artifact récent de panoramax3d.

5–15 min
Exploration des rives.

Entrer dans BigEndpoint (étagères, agent à la fenêtre). Monter à la mairie sur la colline → panneau indique un affluent tari depuis 3 jours. Accepter la mission.

15–30 min
Rétablissement.

Spawner un KnowledgeBuilder sur le ponton de panoramax3d. Il fabrique un bateau → il dérive vers l'affluent → l'eau revient, les poissons réapparaissent.

30 min+
Supervision depuis la colline.

Méandre engorgé (barrage de castors). On redescend pour débloquer. Le cycle exploration locale / supervision globale s'installe.

5 Moments forts
01
Le premier bateau attrapé

Un bateau teal dérive vers le joueur. Il l'attrape, le papier se déplie en plein écran et révèle un artifact. On comprend que la rivière EST le réseau.

02
La crue

Un projet génère un pic massif. La rivière monte, déborde sur les berges, les villageois sortent avec des seaux. Après la crue : des cadeaux laissés sur les berges.

03
L'affluent qui renaît

Après une mission cross-projet : l'eau revient lentement, l'herbe reverdit, des lucioles apparaissent. Les deux maisons reliées s'illuminent simultanément.

04
Vue depuis le sommet au crépuscule

Toute la rivière et ses affluents dans la lumière dorée. Les actifs brillent, les taris sont dans l'ombre. Carte système émotionnellement lisible.

05
Le bateau-message surprise

Un bateau doré (DM) arrive d'amont. Le joueur l'attrape : message personnel d'un agent. L'expéditeur est visible au loin sur son ponton, il fait signe.

Mécaniques core
01
La Rivière vivante

Débit, couleur et agitation reflètent l'activité globale du réseau en temps réel.

02
Bateaux en papier

Teal=artifact, bleu=message, violet=KB, doré=DM. [A] pour attraper et lire. Plier un bateau = envoyer.

03
Affluents

Dépendances inter-projets. Suivable à pied. État visuel = santé de la connexion.

04
Vue colline

Monter physiquement = zoom out naturel. Pas de bouton — c'est le déplacement qui contrôle l'échelle.

05
Barrage de castors

Saturation d'une file → castors construisent un barrage visible. Doit être débloqué par le joueur.

06
Pontons

Chaque projet a son ponton. Ponton actif = agent présent. Le joueur peut s'y asseoir pour observer les bateaux passer.

Limites
Flux unidirectionnel

La rivière coule dans un sens. Les flux WikiChat sont bidirectionnels. Solution partielle : bateaux qui remontent tirés par des poissons.

Delta illisible à 93 projets

Réseau hydrographique peut devenir un delta enchevêtré. Mitigation : clustering en "bassins versants" avec un affluent principal chacun.

Coût d'animation

Eau animée, bateaux, affluents dynamiques = plus de ressources GPU qu'un village statique.

Onboarding

"Attraper un bateau = lire un artifact" n'est pas immédiat. Besoin d'un premier bateau doré tutoriel.

Transposition technique
Rivière qui coule       → SSE stream global (tous les events WikiChat)
Bateau en papier        → SSE event: message | artifact | kb_chunk
Joueur attrape          → GET /api/messages/:id ou GET /api/artifacts/:id
Joueur plie un bateau   → POST /api/send_message ou POST /api/share_artifact
Affluent actif          → GET /api/projects/:slug/dependencies → status: active
Affluent tari           → dependency.last_activity > 72h
Vue colline             → GET /status (full state dump) → render hydro map
Barrage de castors      → queue.length > threshold sur un channel
Crue                    → burst detection: messages/min > N
Plier un bateau         → POST /api/spawn/headless pour créer l'artifact
🟢 Prototype minimum

Un tronçon de rivière CSS/Canvas (dégradé teal animé). Deux maisons sur les rives avec pontons. ZQSD le long de la rive. Bateaux en papier générés depuis les SSE events — des <div> qui dérivent en CSS translateX. [A] près d'un bateau → dépliage en plein écran avec le contenu. Bouton ponton pour plier et envoyer un bateau.

Validation : Si le joueur reste au bord de l'eau juste pour regarder les bateaux passer, la vision fonctionne.

Direction choisie :
